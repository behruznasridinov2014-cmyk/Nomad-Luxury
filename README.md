# NOMAD LUXURY — Премиальная платформа туризма, велнес-резортов и авторских путешествий

> **Слоган бренда:** «Место, где начинается ваш отдых»  
> **Миссия:** Открыть мир природных горных курортов, уединенных спа-шале, архитектурного наследия Шелкового пути и эксклюзивных путешествий.

---

## 💎 О проекте

**NOMAD LUXURY** — это полноценное многостраничное веб-приложение (SPA), разработанное с высочайшим вниманием к деталям арт-дирекшена гостеприимства, типографики, реалистичного глассморфизма и плавной кинематографичной анимации.

Проект создан для соревновательного показа фронтенд-компетенций и сочетает в себе:
- **Эстетику люксового туризма**: теплая слоновая кость (`#F7F6F0`), чистый белый (`#FFFFFF`), глубокий лесной зеленый (`#173F36`), натуральный изумрудный (`#337F6A`), бирюзовый (`#9BD8CA`) и теплый песочный (`#E7D8C1`).
- **Реалистичный CSS-глассморфизм**: глубокое размытие (`backdrop-filter: blur(20px)`), микро-сатурация, деликатные полупрозрачные границы и легкие тени.
- **Полнофункциональный клиентский функционал**: без необходимости в бэкенде, внешних платных API или базах данных. Все данные персистентны через `localStorage`.

## ⚡ Ключевые интерактивные возможности

1. **Командная палитра быстрого поиска (`Ctrl+K` / `Cmd+K`):**
   - Мгновенный поиск по всем направлениям, резортам, турам и статьям.
   - Поддержка стрелок `↑` `↓` и клавиши `Enter` для перехода.
2. **Кинематографичный слайдер Hero:**
   - Счетчик `01 / 05` с микро-прогрессбаром.
   - 3 интерактивных превью-миниатюры.
   - Плавное обновление заголовков, описаний и ссылок при переключении.
3. **Плавающая стеклянная панель поиска:**
   - Выбор направления, дат заезда/выезда и количества гостей.
   - Валидация диапазона дат и автоматическая передача фильтров в каталог.
4. **Языковой переключатель (`RU / EN`):**
   - Мгновенное переключение языка всей навигации, кнопок, форм, фильтров и системных сообщений.
   - Сохранение языка в `localStorage`.
5. **Интерактивный конструктор путешествий:**
   - Генерация персональной программы по дням без обращения к внешним нейросетям или серверам.
6. **Клиентское бронирование с защитой от фейков:**
   - Никаких номеров кредитных карт! Честное предупреждение о демо-режиме и возможность управлять созданными заявками.

## 🛠 Технологический стек

- **React 19**
- **TypeScript 5.7+**
- **Vite 8**
- **Tailwind CSS v4** с кастомными токенами
- **Lucide Icons**
- **Чистый клиентский роутер на History API** (без внешних зависимостей)
- **IntersectionObserver Motion Engine** (с поддержкой `prefers-reduced-motion`)

## 🚀 Установка и локальный запуск

1. Перейдите в директорию проекта:
   ```bash
   cd C:\Users\behru\.gemini\antigravity\scratch\nomad-luxury
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   # или напрямую через node:
   node node_modules/vite/bin/vite.js
   ```

3. Для сборки production-версии:
   ```bash
   npm run build
   # или:
   node node_modules/vite/bin/vite.js build
   ```

4. Откройте в браузере: `http://localhost:5173`
